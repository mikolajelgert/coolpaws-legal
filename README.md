# CoolPaws

Polityka prywatności i regulamin aplikacji **CoolPaws**.

CoolPaws to aplikacja na Androida dla właścicieli psów. Wylicza temperaturę nawierzchni z prognozy i modelu fizycznego, dopasowuje progi do konkretnego psa i ostrzega, zanim zrobi się niebezpiecznie.
